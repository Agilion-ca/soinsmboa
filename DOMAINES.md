## Pour acheter

Option 1 — **Cloudflare Registrar** (recommandé si tu utilises CF Pages) :
- dash.cloudflare.com → Domain Registration → Register
- Prix coûtant (~10$/an), DNS automatiquement sur Cloudflare

Option 2 — **Namecheap** (tu as déjà un compte cPanel là-bas) :
- namecheap.com → chercher le domaine → acheter
- Puis pointer les DNS vers Cloudflare (voir DEPLOY.md)
